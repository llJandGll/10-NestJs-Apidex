# Ejecutar en desarrollo

1. Clonar repositorio
2. Tener nestJs cli instalado

```bash
pnpm install -g @nestjs/cli
```

2. Ejecuta pnpm install

3. Levantar docker - base de datos

```bash
docker-compose up -d
```

4. Conectar con table plus
